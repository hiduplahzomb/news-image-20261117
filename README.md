Sums up the world news of Tuesday 17 November 2026 in one 1024×1024 image. The program draws a newspaper front page in code: the lead story (Ukraine strikes the Kerch Bridge again), four more stories across regions and beats (Iran's drones target the U.S. base in Bahrain, Trump opens his Asia trip at the Quad summit in Manila, Japan scrambles jets after a Russian incursion, Mongolia's president resigns), plus a round-up strip (Depardieu's admission in Paris, COP31's fossil-fuel split, the Pentagon's ninth failed audit). A stdlib-only Python renderer draws everything — text from embedded DejaVu Sans glyphs, vector shapes and icons, a deterministic PNG encoder. No network, no third-party packages; two runs write identical bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
